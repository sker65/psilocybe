LEDs

LEDs actually connected (max. 241, the original lamp with 9 rings). Tip: switch to Solid Color to check that all LEDs light up. Ring and XY effects are designed for the original lamp and only show the part that is connected.

MQTT

Host name or IP address without port, port is always 1883. Max. 19 characters.

Must end with /. Use a different prefix for each lamp.

Creates the light in Home Assistant automatically (JSON schema, with transitions). Leave off if the light is already configured in YAML, otherwise it shows up twice.

Home Assistant JSON schema: commands on <prefix>set, e.g. {"state":"ON","brightness":200,"color":{"r":255,"g":120,"b":0},"transition":2} or {"effect":"Pride"}. State (retained) on <prefix>state, online/offline on <prefix>availability.
Single commands: <prefix>cmd/<action> with actions power (on|off), brightness (0..255), autoplay (0|1), autoplayDuration, pattern (index), palette (0 = Auto, 1..8), paletteName, speed (1..255), solidcolor (#RRGGBB).

Firmware update

Upload .pio/build/d1_mini/firmware.bin. Firmware and web UI are updated together, settings are kept.
